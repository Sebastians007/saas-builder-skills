# Routing Model

The orchestrator routes by **intent + project state + project type**, not stage number.

## Understand

Use when identity, direction, or project type is unclear.

Typical work:
- inspect existing project files;
- summarize current state;
- identify project type;
- capture pivot/change request;
- establish constraints and existing assets.

Avoid:
- stack selection unless constrained already;
- exhaustive market research unless this is a new/pivoted business/product;
- funnel selection.

## Discover

Use when decisions require external/user evidence.

Potential specialists:
- market-sizing
- competitor-teardown
- underserved-market-finder
- trending-tech-scout
- user-acquisition-analyzer
- existing-site/product audit skills

Run only what materially informs the decision.

## Define

Turn evidence into a direction.

Potential specialists:
- avatar-extraction
- offer-extraction
- feature-differentiator
- unique-value-prop-audit
- schwartz-awareness-mapper
- defensibility-calculator
- pricing-model-calculator

Required behavior:
- draft positioning and USP candidates from evidence;
- do not ask the user to invent differentiation from scratch;
- expose assumptions and let the user steer.

## Plan

Translate direction into buildable work.

Potential specialists:
- prd-writer
- mvp-feature-slicer
- feature-roadmap-architect
- user-story-writer
- architecture-decision-writer
- technical-spike-brief
- data-model-diagrammer
- tech-stack-finder

Stack selection usually belongs here.

## Execute

Build the actual thing.

Branches:
- product engineering;
- website/brand;
- service delivery assets/process;
- marketing/funnel;
- content/copy.

Potential specialists are selected from the branch, not universally.

## Verify

Verification can run continuously during Execute and as a pre-launch gate.

Potential specialists:
- test-case-generator
- edge-case-hunter
- regression-test-builder
- browser-verifier
- accessibility-auditor
- security-review-lite
- external installed security scanners when available
- load-test-builder
- user-acceptance-test-planner

## Launch

Potential specialists:
- cloudflare-deployer
- ci-cd-pipeline-builder
- domain-dns-setup
- env-secrets-manager
- monitoring-alerting-setup
- analytics setup

## Operate & Grow

Potential specialists:
- monitoring-alerting-setup
- incident-runbook-writer
- backup-recovery-builder
- growth-dashboard-builder
- revenue-dashboard-builder
- signup-conversion-tracker
- attribution-mapper
- cohort-churn-analyzer
- aha-moment-mapper
- ab-test-generator
- pricing-page-optimizer
- app-performance-report

This phase loops back into Discover/Define when reality contradicts assumptions.
